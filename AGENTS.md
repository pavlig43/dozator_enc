# Правила работы

Для всех русских ответов пользователю применяй skill `writing-simple`: пиши коротко, без воды, канцелярита и лишних англицизмов. Не применяй это правило к коду, именам в коде, точным цитатам ошибок и чужим неизменяемым текстам.

## Windows PowerShell

- Не передавай вывод языковых конструкций `foreach (...) { ... }`, `for (...) { ... }` и `while (...) { ... }` напрямую в конвейер: Windows PowerShell может разобрать это как пустой элемент конвейера.
- Сначала сохраняй вывод цикла в переменную (`$rows = foreach (...) { ... }`), затем запускай отдельный конвейер (`$rows | Format-Table`). Допустимый вариант — обернуть выражение в `@(...)`.
- После ошибки синтаксического анализа не повторяй ту же конструкцию: сначала сведи её к простой форме без конвейера и только затем запускай снова.

## Порядок работы

- Писать пользователю коротко и по делу, на русском.
- Сначала проверять уже открытый или указанный файл и не создавать новые версии без необходимости.
- При удалении оставлять именно те детали, которые пользователь попросил; удалённые файлы отправлять в корзину, а не удалять безвозвратно.

## Штатные решения

- Если штатная правка требует прав администратора, запроси штатное повышение прав.
