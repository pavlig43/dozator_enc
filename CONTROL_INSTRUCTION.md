# Энкодер

Короткое нажатие энкодера выбирает действие. Удержание не меньше 1 с останавливает шнек и открывает меню.

## Главное меню

После пуска LCD показывает выбранный экран:

```text
Select screen
> Work
```

| Действие | Результат |
|---|---|
| Поворот энкодера влево | Предыдущий пункт |
| Поворот энкодера вправо | Следующий пункт |
| Короткое нажатие энкодера | Открыть пункт |
| Удержание энкодера | В меню ничего не делает |

Пункты идут по кругу:

```text
Weight input -> Feed setup -> Calibration -> Work
```

## Целевой вес

```text
Target weight, g
950
```

- Поворот вправо добавляет 50 г.
- Поворот влево вычитает 50 г.
- Диапазон: 50–99950 г.
- Короткое нажатие энкодера сохраняет вес и открывает меню.
- Удержание энкодера не меньше 1 с делает то же самое.

## Порог досыпки

```text
Stop weight, g
50
```

- Поворот вправо добавляет 1 г.
- Поворот влево вычитает 1 г.
- Диапазон: 1–999 г.
- Короткое нажатие энкодера сохраняет порог и открывает меню.
- Удержание энкодера не меньше 1 с делает то же самое.

## Калибровка весов

На пустых весах нажмите энкодер:

```text
Press encoder
to zero
```

После обнуления поставьте груз 1 кг и ждите:

```text
Put 1kg
wait...
```

После записи коэффициента коротко нажмите или удерживайте энкодер:

```text
OK saved
Press to exit
```

## Работа

Когда шнек не работает, LCD показывает `PUSH`:

```text
PUSH 0
Target 950
```

- Короткое нажатие энкодера останавливает шнек, обнуляет весы и запускает новый цикл.
- Удержание энкодера не меньше 1 с останавливает шнек и открывает меню.
- Поворот энкодера на рабочем экране ничего не меняет.
